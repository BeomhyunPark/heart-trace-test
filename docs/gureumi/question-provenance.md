# 구르미 문항 provenance

## 공통 원칙

- 모든 문항은 구르미 프로젝트를 위해 독자적으로 작성했다.
- 공식 TCI 문항과 공식 TCI 해설을 직접 참조하지 않았다.
- 기존 검사 문항의 단어나 상황만 바꾸는 방식으로 만들지 않았다.
- 이론적 construct 수준만 참고했으며, 문항의 상황과 문장은 프로젝트의 독자 콘텐츠다.
- 이 문서는 `GUREUMI_BETA_V01`에 고정한다. 문구·선택지·축·채점 방향이 바뀌면 새 버전을 만들고 provenance를 다시 기록한다.

아래 모든 행의 공통 값은 다음과 같다.

- Origin: original Gureumi item
- Official TCI item referenced: No
- External questionnaire copied: No
