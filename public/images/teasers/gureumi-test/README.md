# 구르미 테스트 티저 이미지

구르미 테스트의 홈 티저와 캐릭터 원본 이미지를 보관합니다.

## 현재 사용하는 파일

### `teaser.png`

- 홈의 작은 티저 카드에서 포스터 미리보기로 사용
- 독립 티저 화면의 레이아웃·색상 참고본
- 독립 화면의 문구와 버튼은 접근성과 반응형 처리를 위해 HTML/CSS로 구현

### 캐릭터 원본

- 티저 화면에서는 색을 숨긴 실루엣으로 표시하며 원본 파일은 변경하지 않음

## 선택 파일

### `share-teaser.png`

- 구르미 티저 공유 기능을 추가할 때 사용할 소셜 미리보기
- 권장 크기: `1200 × 630`

## 파일 최적화

- 홈 미리보기는 가능하면 `500 KB` 이하
- 공유 이미지는 가능하면 `1 MB` 이하
- 색 공간은 `sRGB`
- 투명 배경이 필요하지 않으면 알파 채널 제거
