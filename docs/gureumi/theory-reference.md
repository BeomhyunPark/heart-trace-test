# 구르미 이론 참고 범위와 IP 검토

## 콘텐츠의 성격

구르미 테스트는 Cloninger의 기질 이론에서 논의되는 일부 개념을 construct 수준에서 참고해 만든 독자적인 놀이형 자기이해 콘텐츠다. 공식 TCI 검사도, 공식 검사를 축약하거나 재현한 도구도 아니며 심리학적 진단·평가를 제공하지 않는다.

Beta v0.1은 `NOVELTY`(새로움), `WORRY`(걱정), `RELATION`(관계) 세 축만 사용한다. 27개 상황 문항, 네 단계 양극 응답, 여덟 구르미 캐릭터와 결과 해석은 구르미 프로젝트의 독자 콘텐츠다. 실제 TCI 문항이나 공식 결과 해설은 사용하지 않는다.

사용자 화면에는 다음 고지를 제공한다.

> 이 테스트는 Cloninger의 기질 이론에서 논의된 일부 개념을 참고해 독자적으로 제작한 놀이형 자기이해 콘텐츠입니다. 정식 TCI 검사 또는 심리학적 진단·평가 도구가 아닙니다.

## 출시 전 IP / Legal QA checklist

- [ ] 공식 TCI 문항을 직접 참고하지 않았다.
- [ ] 공식 검사 문장을 복사하지 않았다.
- [ ] 기존 문항의 단어만 바꿔 작성하지 않았다.
- [ ] 공식 결과 해설을 복사하거나 재작성하지 않았다.
- [ ] 공식 검사처럼 보이는 이름/브랜딩을 사용하지 않는다.
- [ ] 정식 TCI 검사라고 표현하지 않는다.
- [ ] 27문항의 provenance가 기록되어 있다.
- [ ] 결과 8종은 구르미 독자 문구를 사용한다.
- [ ] 이론적 참고와 독자 문항을 문서상 구분했다.
- [ ] 사용자에게 비공식 놀이형 콘텐츠임을 고지한다.

이 checklist는 법률상 비침해를 보증하지 않는다. 프로젝트 내부에서 출시 위험을 일관되게 확인하기 위한 절차이며, 별도의 권리 검토가 필요하면 그 결과와 검토 일자를 이 문서에 추가한다.
